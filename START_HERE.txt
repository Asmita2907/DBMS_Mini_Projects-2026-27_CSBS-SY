AURA HEALTH — START HERE

EASIEST WAY TO START
1. Extract this entire ZIP folder first.
2. Open the extracted aura_hospital_site folder.
3. Double-click START_WEBSITE.bat.
4. A server command window will open and your browser will open the website at:
   http://127.0.0.1:5000
5. Keep the AURA Health Server command window open while using the website.
6. To stop the website, close the server command window.

If Windows says Python was not found, install Python from https://www.python.org/downloads/
and select "Add Python to PATH" during installation. Then double-click START_WEBSITE.bat again.

The website uses the included hospital_db.sqlite database. Keep all files in this folder together.
